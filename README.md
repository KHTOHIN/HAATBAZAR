# HaatBazar — Online Supershop System

An online supershop web application with a customer storefront and an admin panel. Developed as an academic project.

## Features

**Customer**
- Browse products
- Shopping cart
- User profile

**Admin**
- Manage products
- Manage customers
- Manage orders
- Sales reports

## Tech Stack

PHP · MySQL

## Getting Started

**Prerequisites:** PHP and MySQL (e.g. XAMPP)

1. Clone the repository into your web server directory (e.g. `htdocs`)
   ```bash
   git clone https://github.com/KHTOHIN/HAATBAZAR.git
   ```
2. Create a database in phpMyAdmin and import `haatbazar.sql`
3. Update the database credentials in `connect.php`
4. Open `http://localhost/HAATBAZAR` in your browser
